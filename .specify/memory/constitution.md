# Constitución del proyecto

## Principios

- Mantener `main` estable y trabajar mediante Pull Request.
- Priorizar cambios pequeños, trazables y reversibles.
- No inventar dependencias, métricas ni controles no aplicables.
- Verificar el comportamiento con pruebas y evidencia real.
- No incluir secretos, credenciales ni datos reales.
- Fusionar mediante merge commit tras revisión y confirmación explícita.
