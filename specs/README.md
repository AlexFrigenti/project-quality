# Especificaciones de cambios

Las especificaciones documentan la intención aprobada antes de implementar cambios funcionales.

- T0: brief, diff y validación.
- T1: spec.md, plan.md, tasks.md, criterios de aceptación y pruebas.
- T2: lo anterior más decisiones, riesgos, invariantes y plan de compatibilidad o reversión.

Cada cambio usa una carpeta `NNN-feature-name/`. La especificación no sustituye al código, las pruebas ni la evidencia de GitHub Actions.

## Plantilla

Copia `000-template/` y sustituye el nombre y el identificador del cambio.
